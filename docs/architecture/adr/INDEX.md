## Guidelines for New ADRs

When making architectural changes:
1. Create a new markdown file named `ADR-XXX.md` sequentially.
2. Include Status (`Draft`, `Accepted`, `Superceded`), Date, Context, Decision, Rationale, and Consequences.
3. Update this `INDEX.md` file.
